# JobBridge BD

JobBridge BD is a responsive career website for job seekers and employers in Bangladesh.

## Features

- Search and filter jobs by keyword, location, type, experience, salary and verified company status
- Category chips for quick browsing
- Save jobs with local browser storage
- Quick apply modal
- Company profile cards
- CV builder with live generated preview
- Candidate dashboard metrics and application timeline
- Responsive design for mobile, tablet and desktop

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Run Locally

Open `index.html` in a browser. No build step is required.
